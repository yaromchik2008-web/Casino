# Casino Victor 🎰

Безкоштовне соціальне казино для розваги на Android та iOS (Expo / React Native).
Лише віртуальні монети: без реальних грошей, без покупок, без виведення.

## Що є
**Лобі:** банери з акціями, пошук, категорії (Популярні, Нові, Слоти, Особливі, Джекпоти, Швидкі, Настільні, Улюблені), нещодавні ігри, сітка всіх ігор.

**23 гри:**
- 13 слотів: 4 класичні (3 барабани, 5 ліній, 2 з прогресивним джекпотом) і 9 відео-слотів (5 барабанів, 10 ліній, wild, scatter, фриспіни, автогра)
- Настільні: європейська рулетка, блекджек, баккара, відеопокер (Jacks or Better), «Більше чи менше»
- Швидкі: Ракета (краш), Міни, Плінко, Кості, Монетка, Колесо удачі

**Бонуси:** щоденний бонус із серією на 7 днів (до 10 000), колесо фортуни кожні 4 години, 500 монет щогодини, кешбек 10%, 6 щоденних завдань, рівні з нагородами.

**Турніри:** тижневий турнір з таблицею лідерів і призами, що нараховуються автоматично.

**Профіль:** рівень, статистика, улюблені ігри, скидання прогресу.

## Запуск на телефоні
1. Встанови Node.js 20+ на комп'ютер.
2. Встанови на телефон застосунок **Expo Go** (Google Play / App Store).
3. У папці проєкту:
   ```bash
   npm install
   npx expo start
   ```
4. Відскануй QR-код камерою (iPhone) або в Expo Go (Android).

## Структура
- `App.tsx` — оболонка: шапка з балансом, нижнє меню, сповіщення
- `src/screens/` — Лобі, Бонуси, Турніри, Профіль, екран гри
- `src/games/` — усі ігри, каталог (`catalog.ts`) і рушій слотів (`slotEngine.ts`)
- `src/state/` — гаманець, рівні, завдання, турнір (зберігаються на пристрої)

Щоб додати новий слот, достатньо дописати запис у `GAMES` у `src/games/catalog.ts`.

## Збірка для магазинів
```bash
npm install -g eas-cli
eas build --platform android   # .aab для Google Play
eas build --platform ios       # потрібен акаунт Apple Developer
```
Google Play і App Store мають окремі правила для «соціальних казино»: вікове обмеження 18+
і позначка про імітацію азартних ігор.

## Друзі (Supabase)

1. Створи проєкт на supabase.com.
2. SQL Editor → New query → встав `docs/supabase.sql` → Run.
3. Authentication → Sign In / Providers → увімкни Anonymous sign-ins.
4. Project Settings → API: скопіюй Project URL і ключ `anon public` у `src/config.ts`.
   Ключ `service_role` у застосунок не вставляй ніколи.
